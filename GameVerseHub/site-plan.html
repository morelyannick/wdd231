GameVerse Hub

Website Planning Document - WDD 231

Site Name

GameVerse Hub

GameVerse Hub was selected because it represents a central place where gamers can discover, review, and organize information about video games. "GameVerse" represents the universe of games and "Hub" represents a place where users can find recommendations and reviews.

Optional Domain: gameversehub.com

Site Purpose

GameVerse Hub is a website created for video game enthusiasts who want to discover new games through reviews, ratings, and recommendations.

  • Display recent game releases.
  • Provide game reviews and ratings.
  • Create a searchable game library.
  • Display a Top 10 ranking.
  • Allow users to save games using Local Storage.
  • Allow visitors to suggest games through a form.
  • Use JSON and external APIs to provide game information.

Scenarios

Scenario 1

I want to play a new game, but I do not know which game is worth buying. Where can I find recommendations?

Scenario 2

I like RPG games. How can I find games with high ratings?

Scenario 3

Can I save games that I want to play later?

Website Pages

Home Page

The homepage introduces the website, displays the Game of the Month, latest releases, and featured reviews.

Game Library

A catalog of games with filters by genre, platform, and rating. Information will be loaded from JSON data.

Top 10 Games

A ranking page showing the best-rated games with reviews and ratings.

Game Details

A detailed page displaying information such as description, developer, platform, release date, screenshots, and ratings.

Suggestions and Wishlist

A page containing a suggestion form and a wishlist system using Local Storage.
